Рабочая папка — это обычная папка на компьютере.
Индекс — это промежуточное хранилище.
Коммит — это фиксация изменений, которые были добавлены в индекс.
Git — сама программа.
GitHub — это онлайн-сервис для работы с Git.
git diff — эта команда показывает разницу между рабочей директорией и индексом.
git diff --staged — эта команда показывает разницу между индексом и последним коммитом.

git status — показывает текущее состояние репозитория.
git diff — эта команда показывает разницу между рабочей директорией и индексом.
git diff --staged — эта команда показывает разницу между индексом и последним коммитом.

Ветка — это указатель на конкретный коммит в истории проекта.
При каждом новом коммите в текущей ветке указатель на неё автоматически сдвигается на этот новый коммит.
Слияние — это процесс объединения изменений из одной ветки в другую.
