git diff - показывает различие между двумя состояниями
git show - показывает объект Git со всеми изменениями
git log - показывает хронологический список коммитов
log -S даёт нам найти нужную строку и когда она удалялась и добавлялась, git blame же показ кто это сделал
git restore отличается от git restore --source= заключается в том, что в первом случае он берёт версию из индекса или из последнего коммита, а второе оттуда, откуда получится
git revert создаёт новый коммит на место старого, когда git reset --hard просто удаляет коммит, безопаснее првый вариант и по причине сохранности и во избежание повреждений
